# CozyXtreme

Kumpulan website yang di-hosting lewat GitHub Pages. Setiap website ada di folder sendiri.

| Folder | Alamat |
|---|---|
| `/` (index.html) | Halaman depan, daftar semua website |
| `cozystore/` | Cozy Store, toko online |

## Menambah website baru

1. Buat folder baru, misalnya `ultah/`.
2. Isi folder itu dengan file website-nya, minimal `index.html`.
3. Tambahkan link ke folder tersebut di `index.html` halaman depan.
4. Commit dan push. Website baru tampil di `https://<alamat-pages>/ultah/`.
